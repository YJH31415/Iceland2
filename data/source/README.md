Source-term values are deliberately separated from meteorology.

Current V3 uses a documented initial ash mass-rate scenario and a fine-ash
size distribution as a software default. Replace these with the selected
published Eyjafjallajökull source inversion before validation.

The model must keep:
- source mass rate [kg/s]
- injection-height distribution
- grain-size distribution
- particle density
- eruption time dependence
as independent inputs.
